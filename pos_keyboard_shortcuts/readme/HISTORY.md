- Configurable POS cashier shortcuts with a per-shop enable flag.
- Search-filter hold Off / 5 / 10 seconds: keep the filter so a second
  match can be tapped, unfocus the box so the barcode scanner works, then
  clear. Skipped when shortcuts are off.

  only on shops that use that method. E/T remain first cash/bank of that
  shop.
- Payment: customer / invoice. Receipt: full / basic print and new order.
- Shortcut badges and help overlay (**H**).
