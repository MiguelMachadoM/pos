POS product grid sort

Configurable grid order, favorites first, top sales

Uses the standard product Sequence field and a configurable sort order for the Point of Sale product grid (per POS configuration).

  • POS product grid order in POS settings (sequence, reference, name, top sales).
  • Favorites first (default on): Odoo favorites before the rest; same inner order.
  • Top sales: optional sort by paid POS quantity; daily cron with editable local time/timezone.

Default sort: Sequence → internal reference → name. Sequence is visible on the product form and editable from the POS. New products default to 1000. On install, Sequence 1 is aligned to 1000; other values are kept.
